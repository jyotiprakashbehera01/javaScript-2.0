Variable :

=> JavaScript is a dynamically typed language because variable types are determined at runtime,
    and a variable can hold values of different data types.

--> A variable in JavaScript is a name placee use to store a value .

console.log('Hello World');
let name  = "jyoti" ;

console.log(name);

--> Three way to declar variable .

1.let = [
    --> It use to variable value may changed .
    --> It has reassign but donot redeclare .
    --> It has block of scoped .
]
2.var = [
    --> It has old method to declaration 
    --> It has reassign and redeclared .
    --> It has function scoped .
]
3.const = [
    --> It has use to don't want to change value .(most use)
    --> It has don't use to reassign or redeclare .
    --> It has block of scoped .
]

What is Scope in variable ?

--> Scope mean where vareable can be access or use in your code .
--> It has three type :
--> Global Scope : When variable can declar outside of function or scope .
--> function Scope : Variable declar inside the function It can normaly use only inside the function .
--> Block Scope : A block is code inside {} .



What is a Data Type in a Variable in JavaScript?

OPERATORS :

1.Arithmatic Operater :

let a = 10;
let b = 3;
console.log(a + b); // 13
console.log(a - b); // 7
console.log(a * b); // 30
console.log(a / b); // 3.333...
console.log(a % b); // 1
console.log(a ** b); // 1000

2.Assignment Operater : Variable mein value assign/update karne ke liye .

let x = 10;
x += 5;  // x = 15
x -= 3;  // x = 12
x *= 2;  // x = 24
x /= 4;  // x = 6

3. Comparision OPerater :

let a = 10;
let b = 20;
console.log(a > b);   // false
console.log(a < b);   // true
console.log(a == b);  // false
console.log(a != b);  // true

== : It can Compare value and Type coneversion .
=== : It can Compare value and Data Type .

4.Logical Operater : condition compare .

let age = 25;
console.log(age > 18 && age < 60); // true

MATH : 

--> Math JavaScript ka built-in object hai,
   jo mathematical calculations ke liye useful methods provide karta hai.

-->
round → nearest
floor → down
ceil → up
trunc → remove decimal
abs → positive
max → biggest
min → smallest
random → random number
sqrt → square root
pow → power

console.log(Math.round(4.4));
console.log(Math.floor(4.9));
console.log(Math.ceil(4.1));
console.log(Math.trunc(-4.9));
console.log(Math.abs(-4.9));
console.log(Math.max(10,20,30,40,50,60));
console.log(Math.min(10,20,30,40,50,60));
console.log(Math.pow(4, 9));
console.log(Math.sqrt(49));
console.log(Math.random());
console.log(Math.sign(0));
